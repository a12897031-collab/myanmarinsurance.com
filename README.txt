Myanmar Insurance Guide — redesigned portable website

OPEN THE WEBSITE
1. Extract the ZIP file.
2. Open the root index.html in Chrome, Edge, Firefox, or another browser.

The root index.html is self-contained. Its CSS, JavaScript, and illustration are inside that file, so you do not need to find or move a separate CSS file.

EDITABLE SOURCE
The source-code folder contains the separate page template, styles.css, script.js, route manifest, icon, and local illustration. Use the root index.html for the simplest run.
